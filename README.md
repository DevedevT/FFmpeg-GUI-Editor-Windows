# SimpleVideoEditor-ML — Free Portable FFmpeg GUI Video Editor for Windows (.exe)

**SimpleVideoEditor-ML** is a lightweight, fast, and **free open-source video editor for Windows** that acts as an intuitive graphical user interface (**FFmpeg GUI**). Designed for users who want to **trim, crop, compress, and convert videos** without learning complex command-line arguments.

This repository provides a **multi-language portable build** with a **ready-to-use `.exe` executable**. No installation, no bloatware, and no watermarks. Licensed under **GPL v3**.

### 🚀 Quick Start & Direct Download (.exe)
You do not need to compile source code, install Python, or manually configure FFmpeg environment variables (`PATH`). Everything is bundled in one portable package:

1. Go to the **[Releases](../../releases)** page of this repository.
2. Download the latest **Windows `.zip` archive** containing the pre-compiled **`.exe` executable**.
3. Extract the folder anywhere on your PC or USB flash drive.
4. Double-click **`SimpleVideoEditor.exe`** to launch the application immediately.

> **100% Portable Software:** Leaves no registry entries and works offline on Windows 10 and Windows 11.

### 🎬 Core Video Editing Features
* **Frame-Perfect Video Trimmer:** Cut and trim video start/end points quickly without re-encoding (lossless stream copy).
* **Video Crop Tool:** Manual crop selection or smart **auto-crop** to remove black bars automatically.
* **Rotate & Flip Video:** Fix video orientation in one click.
* **Video Resizer & Compressor:** Downscale resolution (4K, 1440p, 1080p, 720p) to reduce file size for Discord, Telegram, or web upload.
* **Universal Media Converter:** Convert video and audio between **MP4, MKV, WebM, AVI, GIF, APNG, MP3, WAV, FLAC**, and more.
* **Audio Volume Control:** Adjust audio gain, normalize volume, or mute/remove audio tracks completely.
* **Remove Duplicate Frames:** Automatically detect and delete frozen or duplicate frames to shrink video size.
* **Playback Speed & FPS Changer:** Speed up or slow down video playback and adjust frame rate.
* **Chroma Key (Color Key):** Remove solid background colors from videos and images.

### ⚙️ Advanced FFmpeg & Automation Tools
* **Duplicate Content Finder:** Detect and remove repeated scenes across multiple video files.
* **Image Sequence to Video:** Create smooth MP4 or GIF animations from a collection of PNG/JPG images.
* **Built-in Subtitle Editor:** Create, edit, and synchronize SRT subtitles directly on the video timeline.
* **FFmpeg Command Line Generator:** Visually configure filters and export ready-to-use CLI commands for custom scripts.
* **Batch Video Processing:** Generate `.bat` scripts for drag-and-drop bulk video conversion.
* **Frame Extractor & Alpha Blend:** Export individual video frames or overlay multiple frames using alpha blending.
